# Bash Automation Scripts

A collection of useful Bash shell scripts for automating common Linux tasks.

## Scripts

| File | Description |
|------|-------------|
| backup.sh | Copies files from source to a backup folder |
| file_organizer.sh | Sorts files into subfolders by file extension |
| system_info.sh | Shows hostname, user, date, disk and memory info |

## Usage

chmod +x script_name.sh
./script_name.sh

## Technologies
- Bash
- Linux / Unix shell
